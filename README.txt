بسته نصب چوب‌خط روی GitHub Pages

نسخه: ۳۲

تمام فایل‌های داخل این پوشه را در ریشه Repository بارگذاری کنید.
فایل اصلی برنامه index.html است.

فایل‌های ضروری:
- index.html
- manifest.webmanifest
- sw.js
- choobkhat-180.png
- choobkhat-192.png
- choobkhat-512.png
- choobkhat-maskable-512.png

پس از بارگذاری و فعال‌کردن GitHub Pages، سایت را یک‌بار باز کنید.
در موبایل گزینه Add to Home Screen یا افزودن به صفحه اصلی را بزنید.
نام برنامه «چوب‌خط» و لوگوی رسمی آن نمایش داده می‌شود.

عنوان تب Chrome نیز باید «چوب‌خط — دستیار مدیریت هزینه پروژه» باشد.
در نسخه ۳۲ مرکز کامل گزارش‌ها اضافه شده است: فیلتر پروژه، بازه زمانی، گروه و زیرگروه،
طرف‌حساب، وضعیت، روش پرداخت، ماهیت هزینه، مبلغ و جست‌وجوی متنی؛ همراه با مرتب‌سازی،
انتخاب ستون‌ها، خروجی CSV و JSON و چاپ A4 عمودی یا افقی.

محیط کاری در حالت شب کاملاً با رنگ‌بندی تیره نمایش داده می‌شود. فقط برگه گزارش و چاپ
پس‌زمینه سفید دارد تا خروجی کاغذی خوانا و کم‌مصرف باشد.

اگر قبلاً نسخه قدیمی را روی صفحه اصلی نصب کرده‌اید، ابتدا میانبر قبلی را حذف کنید،
صفحه را یک‌بار با نشانی ?app=choobkhat-v32 تازه‌سازی کنید و سپس دوباره
Add to Home Screen را انجام دهید.
